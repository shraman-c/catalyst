Catalyst

<h2 align="center">
Local-to-Cloud Notes App — turns raw notes into knowledge graphs and flashcards automatically.
</h2>

## Quick start

```bash
cp .env.local.example .env.local   # fill in your values
npm install
npm run dev
```

## Environment variables (see `.env.local.example`)

| Variable | Required | Purpose |
|---|---|---|
| `GROQ_API_KEY` | ✅ | LLM text generation (concept extraction, graph merge, flashcard generation) via the [Groq API](https://console.groq.com/keys) |
| `PINECONE_API_KEY` | ✅ | Vector storage + embeddings via Pinecone inference (`voyage-3-lite`). Create at [app.pinecone.io](https://app.pinecone.io) |
| `PINECONE_INDEX` | – | Index name (default `catalyst`; created automatically on first use) |
| `DATABASE_URL` | ✅ | Supabase Postgres connection string. **In production use the Supabase pooler** (port `6543`) instead of the direct connection (port `5432`) — serverless instances open many short-lived connections, and the pooler (plus `?pgbouncer=true` for transaction mode) handles that without exhausting the project's direct-connection limit. Example: `postgresql://postgres.<ref>:<password>@aws-0-<region>.pooler.supabase.com:6543/postgres?pgbouncer=true`. Also keep the app's Vercel function region in the same region as your Supabase project (e.g. both `us-east-1`) to minimize round-trip latency. |
| `NEXTAUTH_SECRET` | ✅ | Session signing secret (32+ chars) |
| `NEXTAUTH_URL` | ✅ | App URL (e.g. `http://localhost:3000`) |

## Features

- **Automated AI Pipeline**: Extracts concepts, creates relationships, and generates flashcards entirely from uploaded notes.
- **Offline-First Sync Engine**: Built with Dexie.js (IndexedDB), allowing you to work fully offline and seamlessly sync mutations (uploads, cards, renames) to the cloud when reconnected.
- **Immersive Knowledge Graph**: Full-page interactive D3 graph that automatically groups clusters, scales, and zooms to highlight specific concepts or neighborhoods.
- **Multi-File Uploads**: Drag and drop batches of notes with real-time progress tracking.
- **Theme-Aware Brutalist Design**: Floating light/dark mode switch that flawlessly inverts UI elements while respecting the retro-tech aesthetic.

## AI pipeline

1. Notes are chunked and sent to **Groq** (`llama-3.1-8b-instant`) for concept extraction and flashcard generation; graph-merge decisions use the stronger `llama-3.3-70b-versatile` model.
2. Concept/card embeddings are generated by Pinecone's inference API and stored in a serverless Pinecone index (per-subject namespaces) for near-duplicate detection and fuzzy cross-note linking.
3. Graph nodes/edges and flashcards persist to Postgres (Supabase); the graph page renders them dynamically with `react-force-graph-2d`.
